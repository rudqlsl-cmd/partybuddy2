파티버디 설문 구글폼 만들기

버튼 두 번 누르고 붙여넣기만 하면 구글폼이 자동으로 만들어져요. (약 1분)

1

코드 복사

폼을 만드는 코드를 클립보드에 복사해요.

2

Apps Script 열기

구글 계정에 로그인된 상태여야 해요. 새 탭에 빈 스크립트가 열려요.

Apps Script 새로 열기
3

붙여넣고 실행

  1. 편집창의 기존 코드를 전부 지우고 Ctrl+V로 붙여넣기
  2. Ctrl+S로 저장
  3. 위쪽 함수 선택이 createSurvey인지 확인하고 실행
  4. 권한 검토 → 계정 선택 → 고급 → '(프로젝트)로 이동' → 허용
4

폼 링크 확인

아래 '실행 로그'에 수정용 링크와 응답용 링크가 떠요. 구글 드라이브에도 폼이 생겨요. 맘카페에는 응답용 링크를 올리면 돼요.
